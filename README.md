# PPC: Delay No More

Group flight tracker for coordinating travel plans. Built as a PWA with real-time sync.

## Screenshots

|-----------|----------|-------|
| ![Dashboard](docs/demo_dashboard.png) | ![Timeline](docs/demo_timeline.png) | ![Cards](docs/demo_cards.png) |

## Features

- Real-time flight tracking
- Group coordination
- Interactive map view
- Offline support (PWA)

## Tech Stack

- Vanilla JS
- Vite
- Supabase
- Leaflet

## Getting Started

```bash
git clone <repository-url>
npm install
npm run dev
```
